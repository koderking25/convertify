Six flavours 🍧

Pick whichever one your evening requires. MP3 if you want it to just play anywhere. WAV if you are about to do something serious to it. MIDI if you want the actual notes, which is a whole other kind of magic. 🪄

⚡ M4A FASTEST 🎵 MP3 🌊 WAV 💎 FLAC 🎚️ AAC 🎹 MIDI WINK
About that MIDI. 🎹 Convertify does not pretend it can hear music. It hands that job to Midify, its older cousin, which carries 750 MB of models and listens to a recording until it can write the notes down. Install Midify and the MIDI button lights up on its own. Don't, and the other five still work perfectly.

Things it does that it absolutely did not have to 🎁

📂

Opens the folder

The second it finishes, the Finder opens with your file already picked out. No hunting through Downloads muttering "it was called something".

✂️

Takes a slice

Four hour jazz set, and you want the first five minutes? Say so. It fades out before the cut, so it stops like a song rather than like a power failure.

🔁

Remembers for a bit

Same video, second format? It kept the audio. Measured: 5.6s for the first one, then 0.13s for the next. It is not downloading it again like some sort of animal.

🐌

Survives bad wifi

A stall gets noticed in 45 seconds, what already arrived gets kept, and the window tells you your connection is dawdling instead of sitting there looking dead.

🗂️

Keeps a history

Everything you have ever converted, grouped by day, searchable, one click to show it in the Finder or do it again in another flavour.

🔌

Flash drives

Tick a box and it copies onto your USB stick as well. Mildly ridiculous. Extremely useful if you own a piano with a USB port.

It's a plugin. In your DAW. 🎛️

The same window, in a plugin slot, so getting a reference track does not mean leaving the session. Audio passes straight through it untouched — this is not an effect pretending to be useful on the way past, it is somewhere to put the thing you wanted anyway.

🍎 Logic Pro & GarageBandAudio Unit ✅
🎚️ ReaperAU or VST3 ✅
🟠 Ableton LiveVST3 ✅
🎹 Studio One, Cubase, BitwigVST3 ✅
🟥 Pro ToolsAAX, which needs Avid's blessing 😔
Straight answer about tracks. It cannot drop the file onto a track by itself, and neither can anything else: a plugin is handed blocks of audio and the format has no idea the host even has a track list. 🤷 Reaper is the exception, because it lets scripts in — so there is a Reaper script that really does put it on a new track. In Logic, drag it in from the folder that just opened. One drag. 🙂

The plugins

An installer, so you do not have to know which of the two folders an Audio Unit lives in. It puts both where your DAWs look.

Or do it yourself

Both plugin bundles in a zip, for people who would rather drag things into folders personally. We see you. 🫡

Convertify-plugins.zip ⬇️
~/Library/Audio/Plug-Ins/Components
~/Library/Audio/Plug-Ins/VST3
Two things nobody enjoys being surprised by. 🫣 First, macOS will say it is from an unidentified developer, because signing up to be an identified one costs £79 a year. Right-click, choose Open, and tell it you meant it. Second, restart your DAW after installing the plugins: they only go looking for new ones when they start, so one that was already open will insist nothing happened.
